What this does: Adds pmam_email and ward_ids[] fields to old records that don't have them. These are the immutable foreign keys used by the new architecture — once added, future renames of PMAM names or ward labels won't break historical reports.

How it works: For each record without pmam_email, the tool looks up the PMAM by matching the record's name to a user in users collection (fuzzy match supported). For each record without ward_ids[], it converts the wards[] labels to slug IDs via WARD_REGISTRY.

Read-only display: This tool only ADDS new fields. Existing name and wards[] fields are untouched.
