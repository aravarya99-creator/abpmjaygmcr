📤 BULK EXCEL IMPORT
1. Income Import
Paste columns: Month | Interest | Claim (tab or comma separated)
Month can be anywhere in row: Apr-2025, April-25, Apr 25, April 2025
e.g. Apr-2026    0    890344
or: 890344    0    Apr-2026
2. Expenditure Import
Paste columns: FY | Month | Category | Sub Category | Description | Firm / Agency | Amount (₹) | Invoice No | Remarks
(Matches Expenditure table format)
3. Hospital Stats Import
Paste columns: Session (FY) | Patient Treated | Golden Card
(e.g. 2018-19   500   1200)
🗑 BULK DELETE BY FINANCIAL YEAR
⚠ WARNING: This permanently deletes ALL records of the selected type for the chosen FY. This cannot be undone.
1. Delete Income Records
Select FY & Month to delete claim/income entries.
2. Delete Expenditure Records
Select FY & Month to delete expenditure entries.
3. Delete Statistics Records
Select FY & Month to delete hospital statistics.
4. Delete ALL Data for FY
Deletes Income + Expenditure + Stats for the selected FY & Month in one go.
